Claude Code 2.1.285: nuevas opciones de plugins, variables de entorno y mejoras en subagentes

La nueva versión de Claude Code trae controles avanzados para plugins, ajustes gestionados y correcciones en ejecución remota.

Qué pasó

Claude Code lanzó la versión 2.1.285 incorporando importantes novedades técnicas. Se añadió la variable de entorno CLAUDE_CODE_DISABLE_WEB_FETCH para desactivar la herramienta WebFetch y el comando claude --desktop para abrir la app de escritorio en el directorio actual. En la gestión de plugins, ahora se puede usar claude plugin configure para ver opciones y configurar servidores MCP al instalar con claude plugin install --config. Además, se sumó la política allowedProviders para restringir proveedores de API y se corrigieron errores en subagentes, conexiones SSH y manejo de modelos al cambiar a mitad de sesión.

Por qué importa

Para quienes usan Claude Code a diario, estas funciones otorgan un control mucho más fino sobre la seguridad, la gestión de plugins empaquetados y la integración con entornos corporativos o remotos complejos, evitando bloqueos molestos en la terminal.

Qué probar

Prueba abrir la app directamente ejecutando claude --desktop o configura opciones de un plugin con claude plugin configure <plugin>.

Anthropic advierte sobre riesgos existenciales de la IA en su prospecto de salida a bolsa

En documentos para su futura apertura bursátil, Anthropic incluyó advertencias explícitas sobre los peligros existenciales de la tecnología.

Qué pasó

Diversos medios reportaron que, en los documentos oficiales de su proceso hacia la salida a la bolsa, Anthropic dedicó apartados a alertar a los inversores sobre los riesgos severos que su tecnología puede acarrear. La compañía señaló que el desarrollo de inteligencia artificial avanzada conlleva la posibilidad de generar impactos imprevisibles o riesgos existenciales para la humanidad, transparentando los desafíos éticos y de seguridad inherentes al negocio.

Por qué importa

Demuestra la postura pública de Anthropic frente a la gobernanza y los riesgos de sus modelos, priorizando la transparencia ante el mercado financiero sobre el optimismo comercial desmedido.

Anthropic entrega mayor visibilidad a los equipos de seguridad en Claude Code y Cowork

Nuevas herramientas de Anthropic permiten a los equipos de seguridad monitorear de cerca la actividad de agentes y herramientas.

Qué pasó

Anthropic introdujo nuevas capacidades orientadas a los equipos de seguridad de las empresas, entregando mayor visibilidad sobre el uso de Claude Code, Cowork y otros agentes de IA en las organizaciones. Esta funcionalidad permite auditar y supervisar las acciones que realizan las herramientas de IA dentro de los entornos corporativos.

Por qué importa

Facilita la adopción corporativa de herramientas avanzadas al entregar a los departamentos de TI y seguridad el control necesario para cumplir con normativas internas.

Sam Altman presenta Dots, el nuevo agente personal autónomo de OpenAI

OpenAI develó Dots, un asistente personal de funcionamiento continuo diseñado para realizar tareas de manera autónoma.

Qué pasó

Sam Altman presentó oficialmente Dots, un nuevo agente de inteligencia artificial de OpenAI concebido para operar de forma continua y autónoma en segundo plano. El anuncio llega tras decisiones de la compañía de pausar otros desarrollos debido a precauciones de seguridad. Dots busca mantener al usuario en control mientras ejecuta tareas complejas del día a día, posicionándose como la apuesta de OpenAI en el terreno de los agentes personales permanentes.

Por qué importa

Marca un cambio estratégico hacia agentes con autonomía extendida en la competencia directa por asistentes de productividad personal frente a otras herramientas del mercado.
